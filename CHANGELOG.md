# Changelog

All notable Rootline changes are recorded here.

## 0.1.1

Maintenance release.

- Pins direct raw-file install examples to the `v0.1.1` release tag.
- Adds public security reporting guidance.
- Keeps GitHub Wiki and Projects disabled so repository Markdown remains the
  canonical documentation surface.

## 0.1.0

Initial protocol release.

- Defines the Rootline Protocol as a route-aware `AGENTS.md` operating pattern.
- Adds `Route Brief`, `Route Protocol`, `Local Anchors`, `Drift Control`,
  `Receipt Protocol`, `Operator Profile`, and `Route Map` terminology.
- Documents public usage in `README.md`.
- Adds local-copy and raw-file install examples.
- Licenses the project under Apache-2.0.

# Security Policy

Rootline is a documentation-only protocol. It has no package, hosted service,
binary, runtime, dependency graph, or update channel.

## Reporting Security-Sensitive Concerns

Use GitHub's security reporting flow for concerns that should not be discussed
publicly. If that flow is unavailable, contact the maintainer through GitHub
before posting sensitive details.

Security-sensitive concerns include:

- install instructions that could cause unsafe copy/paste behavior;
- examples that could mislead agents into destructive or privileged actions;
- guidance that could cause accidental disclosure of secrets or private project
  context;
- license or provenance issues that affect safe reuse.

For ordinary documentation bugs, compatibility drift, typos, or wording
improvements, use a public GitHub issue.

## Supported Versions

Only the latest published release is actively maintained.
